# MTG Card Swapper - API Routes Planning

## Overview

**Scope:** Phase 1 API endpoints (Django REST Framework)
**Total Routes:** ~36 endpoints across 8 feature groups
**Authentication:** JWT-based (DRF SimpleJWT)
**Base URL:** `https://api.yourdomain.com/api/` (or `http://localhost:8000/api/` for local dev)
**Response Format:** JSON

---

## AUTHENTICATION ROUTES

### 1. User Registration
```
POST /api/auth/register
```
**Purpose:** Create new account (invite-only beta)

**Request:**
```json
{
  "invite_code": "abc123def456...",
  "email": "alice@example.com",
  "password": "SecurePassword123!",
  "username": "alice_trader"
}
```

**Response (201 Created):**
```json
{
  "id": "user-uuid",
  "email": "alice@example.com",
  "username": "alice_trader",
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "created_at": "2024-01-15T10:00:00Z"
}
```

**Validations:**
- Invite code must exist and be valid (status='pending', not expired)
- Email must be valid format + not already registered
- Password must be 8+ chars, have uppercase/lowercase/number/symbol
- Username must be 3-50 chars, alphanumeric + underscores, unique
- French characters allowed (Phase 1.5)

**Error Codes:**
- 400 Bad Request — invalid input
- 409 Conflict — email/username already exists
- 401 Unauthorized — invalid invite code

---

### 2. User Login
```
POST /api/auth/login
```
**Purpose:** Authenticate user, return JWT tokens

**Request:**
```json
{
  "email": "alice@example.com",
  "password": "SecurePassword123!"
}
```

**Response (200 OK):**
```json
{
  "id": "user-uuid",
  "username": "alice_trader",
  "email": "alice@example.com",
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 3600
}
```

**Validations:**
- Email + password must match database
- User account must be active (is_active=true)

**Error Codes:**
- 400 Bad Request — missing fields
- 401 Unauthorized — invalid email/password

---

### 3. Refresh Token
```
POST /api/auth/refresh-token
```
**Purpose:** Get new access token using refresh token (access token expired)

**Request:**
```json
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Response (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 3600
}
```

**Validations:**
- Refresh token must be valid and not expired
- User must still be active

**Error Codes:**
- 401 Unauthorized — invalid/expired refresh token

---

### 4. Logout
```
POST /api/auth/logout
```
**Purpose:** Clear authentication (optional server-side)

**Request:**
```json
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Response (200 OK):**
```json
{
  "detail": "Successfully logged out"
}
```

**Auth Required:** Yes (Bearer token)

**Note:** Phase 1, mainly for frontend (clear localStorage). Server-side token blacklisting optional.

## USER PROFILE ROUTES

### 6. Get User Profile
```
GET /api/users/:id
```
**Purpose:** View another user's profile (public data only)

**Path Parameters:**
- `id` — user UUID

**Response (200 OK):**
```json
{
  "id": "user-uuid",
  "username": "bob_collector",
  "avatar_url": "https://storage.example.com/avatars/bob.jpg",
  "bio": "Casual MTG player",
  "reputation_avg": 4.5,
  "total_swaps_completed": 8,
  "created_at": "2024-01-05T00:00:00Z"
}
```

**Privacy Note:** Location fields (city, region_state, country) NOT included (hidden Phase 1)

**Error Codes:**
- 404 Not Found — user doesn't exist
- 410 Gone — user account deleted

**Ownership Check:** Can only edit own profile (auth.user == :id)

**Request:**
```json
{
  "username": "alice_new_name",
  "avatar_url": "https://storage.example.com/avatars/new-avatar.jpg",
  "bio": "Hardcore MTG collector",
  "preferred_language": "fr"

```

**Response (200 OK):**
```json
{
  "id": "user-uuid",
  "username": "alice_new_name",
  "avatar_url": "https://storage.example.com/avatars/new-avatar.jpg",
  "bio": "Hardcore MTG collector",
  "preferred_language": "fr",
  "updated_at": "2024-01-15T11:00:00Z"

```

**Validations:**
- Username must be 3-50 chars, unique (if changed)
- Bio max 500 chars
- Language must be 'en' or 'fr' (Phase 1)

- 400 Bad Request — invalid data
- 403 Forbidden — can't edit another user's profile

## CARD MANAGEMENT ROUTES

### 10. Create Card
```
POST /api/cards
```
**Purpose:** Add card to your collection (manual entry)

**Auth Required:** Yes (Bearer token)

**Request:**
```json
{
  "scryfall_id": "8b8280fb-31fa-4dc4-b0d1-2b88f01fa4ef",
  "card_name": "Black Lotus",
  "set_code": "LTR",
  "set_name": "The Lord of the Rings",
  "card_type": "Artifact",
  "mana_cost": "{0}",
  "condition": "unused",
  "is_foil": true,
  "language": "English",
  "quantity": 1,
  "is_available": true,
  "notes": "Perfect condition, no wear"
}
```

**Response (201 Created):**
```json
{
  "id": "card-uuid",
  "user_id": "user-uuid",
  "scryfall_id": "8b8280fb-31fa-4dc4-b0d1-2b88f01fa4ef",
  "card_name": "Black Lotus",
  "set_code": "LTR",
  "condition": "unused",
  "is_foil": true,
  "language": "English",
  "quantity": 1,
  "is_available": true,
  "notes": "Perfect condition, no wear",
  "added_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-01-15T10:00:00Z"
}
```

**Validations:**
- scryfall_id must be valid UUID (from Scryfall API)
- condition must be one of: 'unused', 'played', 'damaged'
- language must be valid (English, French, Japanese, etc.)
- quantity must be > 0
- User can add same card multiple times (each copy = separate row)

**Error Codes:**
- 400 Bad Request — invalid card data
- 401 Unauthorized — not authenticated

### 11. Search Cards (Global)
```
GET /api/cards/search?name=&set=&condition=&foil=&language=
```
**Purpose:** Search for cards across all users' collections

**Query Parameters:**
- `name` (required) — card name or partial (e.g., "Black")

- `condition` (optional) — 'unused', 'played', 'damaged'
- `foil` (optional) — true/false
- `language` (optional) — 'English', 'French', etc.

**Response (200 OK):**
```json
{
  "count": 5,
  "results": [
    {
      "card": {
        "id": "card-uuid-1",
        "card_name": "Black Lotus",
        "set_code": "LTR",
        "condition": "unused",
        "is_foil": true
      },
      "available_from": [
        {
          "user_id": "user-uuid-1",
          "username": "alice_trader",
          "reputation_avg": 4.8,
          "quantity": 1,
          "condition": "unused",
          "is_foil": true
        },
        {
          "user_id": "user-uuid-2",
          "username": "bob_collector",
          "reputation_avg": 4.5,
          "quantity": 2,
          "condition": "played",
          "is_foil": false
        }
      ]
    }

}
```

**Sorting:** By user reputation (highest first)

**Performance:** Indexed on card_name, scryfall_id for fast queries

**Error Codes:**
- 400 Bad Request — missing name parameter
- 404 Not Found — no cards match

```

```

**Purpose:** Initiate swap with another user

**Auth Required:** Yes (Bearer token)

**Request:**
```json
{
  "target_user_id": "bob-uuid",
  "offered_card_ids": ["alice-card-1", "alice-card-2"],
  "requested_card_ids": ["bob-card-1"]
}
```

**Response (201 Created):**
```json
{
  "id": "offer-uuid",
  "initiator_user_id": "alice-uuid",
  "initiator": {
    "username": "alice_trader",
    "avatar_url": "..."
  },
  "target_user_id": "bob-uuid",
  "target": {
    "username": "bob_collector",
    "avatar_url": "..."
  },
  "status": "pending",
  "counteroffer_count": 0,
  "expires_at": "2024-01-22T10:00:00Z",
  "offer_items": [
    {
      "id": "item-uuid-1",
      "card_id": "alice-card-1",
      "card": {
        "card_name": "Llanowar Elves",
        "condition": "played"
      },
      "item_type": "offered"
    },
    {
      "id": "item-uuid-2",
      "card_id": "alice-card-2",
      "card": {
        "card_name": "Forest",
        "condition": "unused"
      },
      "item_type": "offered"
    },
    {
      "id": "item-uuid-3",
      "card_id": "bob-card-1",
      "card": {
        "card_name": "Black Lotus",
        "condition": "unused"
      },
      "item_type": "requested"
    }
  ],
  "created_at": "2024-01-15T10:00:00Z"
```

**Validations:**
- target_user_id must exist and not be same as requester
- offered_card_ids must all belong to requester
- requested_card_ids must all belong to target user
- Cards must have is_available=true
- At least 1 offered card and 1 requested card

**Error Codes:**
- 400 Bad Request — invalid card selections
- 403 Forbidden — doesn't own offered cards
- 404 Not Found — user/card doesn't exist

### 20. Accept Offer
```
POST /api/offers/:id/accept
```
**Purpose:** Target accepts offer, creates swap_details, unlocks messaging

**Auth Required:** Yes (Bearer token)

**Permission:** Only target_user_id can accept

**Constraint:** status must = 'pending'

**Request:** Empty body

**Response (200 OK):**
```json
{
  "id": "offer-uuid",
  "status": "accepted",
  "accepted_at": "2024-01-15T11:00:00Z",
  "swap_details": {
    "id": "swap-detail-uuid",
    "offer_id": "offer-uuid",
    "swap_mode": null,
    "mode_decided_at": null,
    "created_at": "2024-01-15T11:00:00Z"
  },
  "offer_items": [...]
}
```

**Side Effects:**
- Creates swap_details row
- Unlocks messaging table access
- Expires_at is NOT changed when accepting (still 7 days from offer creation)

**Error Codes:**
- 403 Forbidden — not target user
- 400 Bad Request — offer not in pending status
- 409 Conflict — offer expired

### 22. Counteroffer
```
POST /api/offers/:id/counteroffer
```
**Purpose:** Propose different cards, renew 7-day timer

**Auth Required:** Yes (Bearer token)

**Permission:** Only if you're NOT the last counterofferrer (allow both sides to counter)

**Constraint:** counteroffer_count < max_counteroffers (< 4)

**Request:**
```json
{
  "offered_card_ids": ["bob-card-1", "bob-card-3"],
  "requested_card_ids": ["alice-card-2"]
}
```

**Response (200 OK):**
```json
{
  "id": "offer-uuid",
  "status": "pending",
  "counteroffer_count": 1,
  "expires_at": "2024-01-22T10:00:00Z",  # EXTENDED 7 more days
  "offer_items": [
    {
      "card_id": "bob-card-1",
      "item_type": "offered"
    },
    {
      "card_id": "bob-card-3",
      "item_type": "offered"
    },
    {
      "card_id": "alice-card-2",
      "item_type": "requested"
    }
  ]
}
```

**Side Effects:**
- Old offer_items deleted (replaced with new)
- counteroffer_count incremented
- expires_at extended by 7 days (app logic, not automatic)
- status remains 'pending' (not 'counteroffered')

**Error Codes:**
- 403 Forbidden — not offer participant or already made last counteroffer
- 400 Bad Request — invalid cards
- 409 Conflict — max counteroffers reached (4)

## SWAP DETAILS ROUTES (Post-Acceptance Coordination)

### 33. Get New Messages (Polling)
```
GET /api/offers/:id/messages?since=2024-01-15T10:30:00Z
```
**Purpose:** Poll for new messages (2-5s refresh from frontend)

**Query Parameters:**
- `since` (required) — ISO 8601 timestamp, returns messages created after this time

**Response (200 OK):**
```json
{
  "count": 2,
  "results": [
    {
      "id": "message-uuid-3",
      "sender": { "username": "alice_trader" },
      "content": "Perfect! Saturday 2pm at Starbucks?",
      "created_at": "2024-01-15T10:35:00Z"
    },
    {
      "id": "message-uuid-4",
      "sender": { "username": "bob_collector" },
      "content": "Sounds perfect!",
      "created_at": "2024-01-15T10:36:00Z"
    }
  ]
}
```

**Frontend Implementation:**
1. Load offer messages (GET /api/offers/{id}/messages)
2. Store `last_message_timestamp` = latest message's created_at
3. Poll every 2-5 seconds: GET /api/offers/{id}/messages?since={last_message_timestamp}
4. Append new messages to UI
5. Update last_message_timestamp

**Error Codes:**
- 400 Bad Request — invalid since timestamp
- 403 Forbidden — not offer participant
- 404 Not Found — offer doesn't exist

## COMMON PATTERNS & CONVENTIONS

### Request Headers (All Requests)
```
Content-Type: application/json
Authorization: Bearer {jwt_token}  (except auth routes)
Accept-Language: en  (Phase 1.5+, for multilingual)
```

### Response Format
All responses follow standard JSON structure:
- Success (2xx): `{ "id": "...", "field": "value", ... }`
- Error (4xx/5xx): `{ "detail": "error message" }` or `{ "field": ["error message"] }`

### Pagination
Standard cursor-based pagination:
```json
{
  "count": 42,
  "next": "https://api.../endpoint?offset=20",
  "previous": "https://api.../endpoint?offset=0",
  "results": [...]
}
```

### Timestamps
All timestamps are ISO 8601 with timezone: `2024-01-15T10:00:00Z`

### Error Codes
- 200 OK — success
- 201 Created — resource created
- 204 No Content — success, no response body
- 400 Bad Request — invalid input
- 401 Unauthorized — not authenticated
- 403 Forbidden — authenticated but not permitted
- 404 Not Found — resource doesn't exist
- 409 Conflict — business logic violation
- 500 Internal Server Error — server error

### Authentication Flow
1. POST /auth/register → get access_token + refresh_token
2. Store tokens in localStorage/cookie
3. Include `Authorization: Bearer {access_token}` in all authenticated requests
4. When access_token expires (3600s), POST /auth/refresh-token to get new one
5. If refresh_token expires, user must login again
