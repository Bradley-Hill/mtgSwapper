# Database Schema - VALIDATED & FINALIZED

## Schema Changes from Walkthrough

### TABLE 1: users (✅ CONFIRMED)
**Changes:**
- Username: **Editable** (users can change)
- Avatar: **URL only** (use Supabase/Render storage, just reference URL)
- Language: **en/fr Phase 1** (constraint updated)
- Location: **Hidden Phase 1, used Phase 2+**
- Reputation: **Calculated on-read** (from ratings table, slower but always current)
- **Include:** is_admin, last_login_at (low-cost, future-useful)
- **Remove:** audit tracking for username changes

**Updated SQL:**
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    username VARCHAR(50) UNIQUE NOT NULL,  -- EDITABLE
    avatar_url VARCHAR(500) NULL,  -- URL ONLY (external storage)
    bio TEXT NULL,
    preferred_language VARCHAR(5) DEFAULT 'en',  -- CONSTRAINT: ('en', 'fr')
    city VARCHAR(100) NULL,  -- HIDDEN Phase 1
    region_state VARCHAR(100) NULL,
    country VARCHAR(100) NULL,
    reputation_avg DECIMAL(3, 2) DEFAULT 0.00,  -- CALCULATED from ratings
    total_swaps_completed INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    is_admin BOOLEAN DEFAULT FALSE,  -- KEEP for Phase 1.5+
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    last_login_at TIMESTAMP WITH TIME ZONE NULL,  -- KEEP tracking
    CONSTRAINT valid_language CHECK (preferred_language IN ('en', 'fr')),
    CONSTRAINT valid_reputation CHECK (reputation_avg >= 0 AND reputation_avg <= 5)
);

CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_created_at ON users(created_at DESC);
```

### TABLE 2: invite_codes (✅ CONFIRMED)
**Changes:**
- Duplicate handling: **Update/replace old code** (reset expiry on re-invite)
- Code format: **Random 32-char token** (via secrets.token_urlsafe)
- Expiry: **30 days** (reasonable)
- **Add status:** 'cancelled' (for revoking invites)
- **Keep inviter_user_id:** For future community features (who invited whom)

**Updated SQL:**
```sql
CREATE TABLE invite_codes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    inviter_user_id UUID NOT NULL REFERENCES users(id) ON DELETE SET NULL,
    invitee_email VARCHAR(255) UNIQUE NOT NULL,  -- UNIQUE enforces one pending per email
    code VARCHAR(50) UNIQUE NOT NULL,  -- RANDOM TOKEN
    status VARCHAR(20) DEFAULT 'pending',
    accepted_user_id UUID NULL REFERENCES users(id) ON DELETE SET NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    accepted_at TIMESTAMP WITH TIME ZONE NULL,
    expires_at TIMESTAMP WITH TIME ZONE DEFAULT (CURRENT_TIMESTAMP + INTERVAL '30 days'),
    CONSTRAINT valid_status CHECK (status IN ('pending', 'accepted', 'rejected', 'expired', 'cancelled')),
    CONSTRAINT future_expiry CHECK (expires_at > created_at)
);

CREATE INDEX idx_invite_codes_code ON invite_codes(code);
CREATE INDEX idx_invite_codes_email ON invite_codes(invitee_email);
CREATE INDEX idx_invite_codes_status ON invite_codes(status);
```

### TABLE 3: cards (✅ CONFIRMED WITH CHANGES)
**Changes:**
- Denormalization: **YES** (store card_name, set_code for fast search)
- Condition values: **SIMPLIFIED** (Unused, Played, Damaged instead of 6 values)
- Language tracking: **YES** (include for non-English cards)
- Upload method flags: **SKIP** (is_scanning_upload, is_bulk_upload removed)
- Quantity: **KEEP** (multiple copies in one row allowed)

**Updated SQL:**
```sql
CREATE TABLE cards (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- Scryfall Data (denormalized for fast search)
    scryfall_id VARCHAR(255) NOT NULL,
    card_name VARCHAR(255) NOT NULL,
    set_code VARCHAR(10) NOT NULL,
    set_name VARCHAR(255) NULL,
    card_type VARCHAR(255) NULL,
    mana_cost VARCHAR(50) NULL,
    
    -- Card Attributes
    condition VARCHAR(30) NOT NULL DEFAULT 'played',
    -- SIMPLIFIED: 'unused', 'played', 'damaged'
    is_foil BOOLEAN DEFAULT FALSE,
    language VARCHAR(50) DEFAULT 'English',  -- 'English', 'French', 'Japanese', etc
    quantity INTEGER DEFAULT 1 CHECK (quantity > 0),
    
    -- Status
    is_available BOOLEAN DEFAULT TRUE,
    
    -- Optional user notes
    notes TEXT NULL,
    
    -- Timestamps
    added_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT valid_condition CHECK (condition IN ('unused', 'played', 'damaged'))
);

CREATE INDEX idx_cards_user_id ON cards(user_id);
CREATE INDEX idx_cards_scryfall_id ON cards(scryfall_id);
CREATE INDEX idx_cards_card_name ON cards(card_name);
CREATE INDEX idx_cards_user_available ON cards(user_id, is_available);
```

### TABLE 4: offers (✅ CONFIRMED)
**Changes:**
- Counteroffer tracking: **Keep 'pending' status, use counteroffer_count** (simpler)
- Timer renewal: **App logic** (DRF endpoint updates expires_at on counteroffer)
- Max counteroffers: **4** (balanced)
- Last counteroffered by: **REMOVE** (not needed if app handles logic)

**Updated SQL:**
```sql
CREATE TABLE offers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    initiator_user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    target_user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- Status & Negotiation
    status VARCHAR(30) DEFAULT 'pending' NOT NULL,
    -- 'pending' ('no response' or 'awaiting counterresponse')
    -- 'accepted' ('both agreed')
    -- 'declined' (rejected)
    -- 'expired' (7-day timer elapsed)
    -- 'cancelled' (cancelled by initiator)
    -- 'completed' (swap done, rated)
    
    counteroffer_count INTEGER DEFAULT 0,  -- Tracks negotiation rounds
    max_counteroffers INTEGER DEFAULT 4,
    
    -- Expiration & Lifecycle
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP WITH TIME ZONE DEFAULT (CURRENT_TIMESTAMP + INTERVAL '7 days'),
    accepted_at TIMESTAMP WITH TIME ZONE NULL,
    completed_at TIMESTAMP WITH TIME ZONE NULL,
    declined_at TIMESTAMP WITH TIME ZONE NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT valid_status CHECK (status IN (
        'pending', 'accepted', 'declined', 'expired', 'cancelled', 'completed'
    )),
    CONSTRAINT initiator_not_target CHECK (initiator_user_id != target_user_id),
    CONSTRAINT valid_counteroffer CHECK (counteroffer_count >= 0 AND counteroffer_count <= max_counteroffers)
);

CREATE INDEX idx_offers_initiator ON offers(initiator_user_id);
CREATE INDEX idx_offers_target ON offers(target_user_id);
CREATE INDEX idx_offers_status ON offers(status);
CREATE INDEX idx_offers_status_expires ON offers(status, expires_at);
```

### TABLE 5: offer_items (✅ CONFIRMED WITH CHANGE)
**Change:**
- Quantity field: **REMOVE** (simplify to one row per card, each copy = separate entry)
- This means: If offering 3x "Llanowar Elves" + 2x "Forest", that's 5 separate offer_items

**Updated SQL:**
```sql
CREATE TABLE offer_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    offer_id UUID NOT NULL REFERENCES offers(id) ON DELETE CASCADE,
    card_id UUID NOT NULL REFERENCES cards(id) ON DELETE CASCADE,
    item_type VARCHAR(20) NOT NULL,  -- 'offered' or 'requested'
    added_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT valid_item_type CHECK (item_type IN ('offered', 'requested')),
    CONSTRAINT unique_offer_item UNIQUE (offer_id, card_id, item_type)  -- No duplicates
);

CREATE INDEX idx_offer_items_offer_id ON offer_items(offer_id);
CREATE INDEX idx_offer_items_card_id ON offer_items(card_id);
```

### TABLE 6: swap_details (✅ CONFIRMED)
**Changes:**
- Address deletion: **Immediately after marked complete** (not 24h delay)
- In-person coordination: **Store proposed_location + proposed_datetime** in DB
- Confirmation: **Two-step (both initiator & target confirm location/time)**

**Updated SQL:**
```sql
CREATE TABLE swap_details (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    offer_id UUID UNIQUE NOT NULL REFERENCES offers(id) ON DELETE CASCADE,
    
    -- Swap Mode Decision (Post-Acceptance)
    swap_mode VARCHAR(20) NULL,  -- 'in_person' or 'mail'
    mode_decided_at TIMESTAMP WITH TIME ZONE NULL,
    
    -- IN-PERSON MODE
    proposed_location TEXT NULL,
    proposed_datetime TIMESTAMP WITH TIME ZONE NULL,
    in_person_confirmed_initiator BOOLEAN DEFAULT FALSE,
    in_person_confirmed_target BOOLEAN DEFAULT FALSE,
    in_person_confirmed_at TIMESTAMP WITH TIME ZONE NULL,
    
    -- MAIL MODE (Addresses = Phase 2, for now simplified)
    shipping_from_address TEXT NULL,
    shipping_to_address TEXT NULL,
    carrier VARCHAR(50) NULL,  -- 'USPS', 'UPS', 'FedEx', 'DHL'
    outbound_tracking_number VARCHAR(255) NULL,
    
    -- Completion
    swap_completed_at TIMESTAMP WITH TIME ZONE NULL,
    addresses_deleted_at TIMESTAMP WITH TIME ZONE NULL,  -- Auto-delete IMMEDIATELY post-completion
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT valid_swap_mode CHECK (swap_mode IN ('in_person', 'mail')),
    CONSTRAINT valid_carrier CHECK (carrier IN ('USPS', 'UPS', 'FedEx', 'DHL') OR carrier IS NULL)
);

CREATE INDEX idx_swap_details_offer_id ON swap_details(offer_id);
CREATE INDEX idx_swap_details_swap_mode ON swap_details(swap_mode);
```

### TABLE 7: messages (✅ CONFIRMED)
**Changes:**
- Read receipts: **SKIP Phase 1** (add in Phase 2)
- Tracking: Just create_at, no read_at tracking needed

**Updated SQL:**
```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    offer_id UUID NOT NULL REFERENCES offers(id) ON DELETE CASCADE,
    sender_user_id UUID NOT NULL REFERENCES users(id) ON DELETE SET NULL,
    content TEXT NOT NULL,
    is_system_message BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT content_not_empty CHECK (LENGTH(TRIM(content)) > 0)
);

CREATE INDEX idx_messages_offer_id ON messages(offer_id);
CREATE INDEX idx_messages_created_at ON messages(created_at DESC);
CREATE INDEX idx_messages_offer_created ON messages(offer_id, created_at DESC);
```

### TABLE 8: ratings (✅ CONFIRMED)
**Changes:**
- Link to offer: **YES** (offer_id for context, why you rated them)
- Comment length: **500 chars** (kept)

**Updated SQL:**
```sql
CREATE TABLE ratings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    rater_user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    rated_user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    offer_id UUID NOT NULL REFERENCES offers(id) ON DELETE CASCADE,  -- LINK TO SWAP
    rating_stars INTEGER NOT NULL CHECK (rating_stars >= 1 AND rating_stars <= 5),
    comment TEXT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT rater_not_rated CHECK (rater_user_id != rated_user_id),
    CONSTRAINT comment_length CHECK (LENGTH(TRIM(comment)) <= 500 OR comment IS NULL),
    CONSTRAINT one_rating_per_swap UNIQUE (rater_user_id, offer_id)
);

CREATE INDEX idx_ratings_rated_user ON ratings(rated_user_id);
CREATE INDEX idx_ratings_by_user_created ON ratings(rated_user_id, created_at DESC);
```
